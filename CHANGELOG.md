# Что нового

## 0.1.1

- Две раскладки у каждой страницы: горизонтальная и вертикальная. В редакторе переключатель «Горизонтально / Вертикально», телефон сам берёт нужную при повороте
- Клавиши растягиваются на весь экран телефона, пустых полей по краям больше нет. Квадратные клавиши — по желанию
- Редактор показывает пульт в пропорциях экрана вашего телефона
- Громкость заливается по форме клавиши: высокая — снизу вверх, широкая — слева направо
- Окно «USB-кабель» подсказывает, если телефон подключён, но отладка по USB выключена, с инструкциями для Samsung и Xiaomi

## 0.1.0

Первая версия.

- Пульт на телефоне открывается в браузере по QR-коду, ставить ничего не нужно
- Подключение по USB-кабелю через adb: задержка 1–3 мс, приложение находит ПК само
- OBS: сцены, коллекции, стрим, запись, повтор, виртуальная камера, микрофон, источники, громкость входов
- Состояние видно сразу: светодиод у сцены в эфире, клавиша краснеет, когда идёт стрим или запись, выключенный микрофон гаснет
- Сочетания клавиш с удержанием, запуск программ, текст, медиаклавиши, громкость ПК и отдельных программ
- Долгое нажатие — второе действие на той же кнопке
- Объёмные клавиши, которые хочется нажать: блик, грань, тень, светодиод состояния, 8 насыщенных цветов, картинки и GIF, 1500 значков Phosphor, логотипы брендов
- Экран телефона не гаснет, пока открыт пульт
- Приложение для Android: полный экран, экран не гаснет, сканер QR-кода, вибрация, проверка новых версий
- Автообновление программы на ПК с GitHub
